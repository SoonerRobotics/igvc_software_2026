# EStop Remote PCB

This is the EStop Remote from 2021. It uses a [Adafruit Feather M0 with RFM95 LoRa Radio - 900MHz - RadioFruit](https://www.adafruit.com/product/3178) board.

Required Libraries
- RadioHead [Arduino Library Download](https://github.com/adafruit/RadioHead/archive/master.zip)
- LiquidCrystal_PCF8574 by Matthias Hertel
